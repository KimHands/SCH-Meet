## 3. 기능별 상세 (필수 기능만 상세 작성)

### F-001 메모 목록 조회

- **사용자 동작:** 메인 페이지 접속 시 자동 호출
- **호출 API:** `GET /api/memos/`
- **성공 시 UI:** 최신순 정렬된 카드 리스트
- **빈 상태:** "아직 메모가 없습니다" 안내 + 작성 버튼
- **에러 상태:** "불러오지 못했어요. 새로고침 해주세요." 메시지

### F-002 메모 작성

- **사용자 동작:** 메인의 "+" 버튼 클릭 → 작성 화면 이동
- **입력 항목:** 제목(필수, 1~50자), 내용(선택, 최대 500자)
- **호출 API:** `POST /api/memos/` (body: `{title, content}`)
- **성공 시:** 작성 완료 토스트 → 메인으로 이동, 목록 갱신
- **검증 실패:** 빨간 테두리 + "제목을 입력해주세요"

   │

   │                          │
   │                          └──▶ [삭제 confirm] ──▶ (DELETE) ──▶ [메인]

   └──▶ [검색 /?q=...]
