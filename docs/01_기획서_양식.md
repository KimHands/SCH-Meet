## 6. 사용자 시나리오

> "한 사용자가 우리 서비스를 처음 켜서 → 핵심 가치를 경험할 때까지의 흐름"을 글로 써본다.

```
(예시)
1. 사용자가 메인 페이지에 접속한다.
2. 오늘 운동했냐는 질문에 "예"를 누르면 기록 페이지로 이동.
3. 종목(예: 푸시업) 선택 → 세트 수 입력 → 저장.
4. 메인으로 돌아오면 이번 주 운동 횟수가 캘린더에 표시된다.
5. 캘린더의 날짜를 누르면 그날 기록 상세를 볼 수 있다.
```
